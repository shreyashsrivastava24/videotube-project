🎥 VideoTube

A full-stack video-sharing platform inspired by YouTube, built using the MERN stack. VideoTube allows users to upload videos, interact with content, manage their channels, and experience a modern video streaming platform.

🚀 Live Demo

Live: https://videotube-project-1-1qvk.onrender.com

📂 Repository

GitHub: https://github.com/shreyashsrivastava24/videotube-project

---

✨ Features

- 🔐 JWT Authentication (Access & Refresh Tokens)
- 🎥 Upload Videos & Thumbnails
- ❤️ Like Videos
- 💬 Comment System
- 🔔 Subscribe / Unsubscribe Channels
- 📜 Watch History
- 📂 Playlists
- 👤 Channel Profile Management
- 📝 Tweets
- 📊 User Dashboard
- 📱 Fully Responsive UI

⚙️ Installation

git clone https://github.com/shreyashsrivastava24/videotube-project.git

cd videotube-project

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install

Create a ".env" file and configure the required environment variables.

Run the application:

# Backend
npm run dev

# Frontend
npm run dev
